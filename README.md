# دليل الطالب العراقي
موقع ثابت (بدون Backend) يبحث داخل ثلاثة أدلة PDF فقط، موجودة في `pdf/`:
gov.pdf (الدليل الحكومي 2025-2026)، private.pdf (الجامعات الأهلية 2026)، basra.pdf (شبكة أهل البصرة 2026-2027).
`data/*.json` نص كل صفحة مستخرج من الـPDF بـ pdftotext (للبحث فقط). الاستخراج يفقد بعض الحروف العربية، فالمرجع الصحيح هو صفحة الـPDF المعروضة.
## النشر
ارفع المجلد كاملاً إلى مستودع GitHub، ثم Settings > Pages > Deploy from branch (main, root). المسارات نسبية فتعمل من مسار فرعي.
لا يعمل بفتح index.html مباشرة من الجهاز (المتصفح يمنع fetch من file://).
